# HWPX 표 선언 크기 조회와 무변경 확인 보존

HWPX 표는 크기를 common에 저장하고 HWP용 raw 헤더를 만들지 않는다. 기존 getter는 raw 필드가 없으면 0을 반환했다. 선언 폭/높이가 있는 일반 표·병합 표도 속성창에서 0.0mm로 보였다. raw 크기 필드가 있으면 기존 값을 우선하고, 없는 필드만 common의 선언 크기로 조회한다. 셀 합계를 추정하지 않으므로 자동/미지정 0을 그대로 유지한다. 파서·렌더러·직렬화 제품 코드는 변경하지 않았다.

같은 속성창의 변경 없는 확인은 표의 공통 테두리/채우기를 셀 전체에 다시 적용했다. 개별 서식이 있는 셀의 전체 SVG가 바뀌는 현상을 구버전 실제 Mac Chrome에서 재현했다. UI는 변경 없는 속성만 제거하고 변경이 있을 때만 setter를 호출한다. 테두리/채우기는 setter의 trigger 필드를 유지하도록 묶음으로 비교한다. 명시적 셀 크기 변경은 기존 서식을 보존하고 undo/redo에 기록된다. 크기 설명은 선언값과 자동/미지정 0의 의미를 안내한다.

## 최종 검증

- 작은 일반·병합·폭 자동·높이 자동·양쪽 자동·개별 셀 서식 등 6상태. WASM 24파일/72재열기와 snapshot undo/redo 6사례의 성공 기록을 재사용하고 최종 제품 파일 hash 불변을 확인했다. 기존 동일 바이트 12파일은 전체 SVG·셀 크기·본문이 유지됐다.
- 현재 소스와 현재 WASM을 실제 headed Mac Chrome에서 실행했다. 읽기 전용 mm 표시, 무변경 확인, 편집 초안 취소, 명시적 셀 크기 변경, 기존 테두리/채우기 보존, 실제 CommandHistory undo/redo 12쌍, HWP/HWPX 저장 재열기 24건을 통과했다.
- 최종 소스에서 Native example을 다시 빌드했다. 현재/기존 표 저장물 168건의 같은 바이트 getter·셀 크기·전체 SVG와 Native 두 형식 재저장 336회를 비교했다. 선언/자동 0, 부분 raw 헤더의 우선순위, 조회/저장 모델 무변경, 명시적 크기 변경과 snapshot undo/redo도 확인했다. 캐시 복원 후 보관 바이너리로 동일 검사를 재실행했다.
- 투명 채우기 회귀: WASM 8상태/48파일/240재열기, Native 48파일/96재저장. 실제 Chrome 9상태/undoRedo 54쌍/90저장 재열기. 전체 desktop 테스트는 36 pass/0 fail/선택적 개인 layout fixture 1 skip/0 TODO다. 스타일 전파 16입력/32재열기, 스타일 삭제, 셀 수식, UI 컨트롤러, 저장 보호를 포함한다. 실제 소스 host handler/파일시스템 회귀 19묶음도 통과했다.
- TypeScript noEmit, Node driver 구문 검사, 최종 Rust lib/example strict Clippy(-D warnings), git diff --check 통과.

## 엄격 비교 차이와 실행 범위

HWPX 바깥 여백 getter의 기존 raw-only 경로는 선언 283을 0으로 표시하고, HWP 재열기는 283을 반환한다. 구버전에서도 같은 차이를 확인했고 원래 XML의 283은 보존됐다. Chrome 저장 비교는 이 네 조회값만 0→283으로 정확히 제한해 기록하며 크기·다른 속성·텍스트·스타일·전체 SVG는 동일해야 한다. 이 기존 getter 결함은 이번 크기 수정에 포함하지 않았다. 패턴 없음 0/-1 표현 차이도 별도 기록한다.

처음 Native/standalone WASM과 Chrome의 SVG는 달랐다. UI 초기화가 적용하는 잘림보기 설정(clipEnabled=false)을 동일하게 적용하면 이번 표 저장물 24건, 이전/현재 채우기 저장물 각 90건이 전체 SVG까지 정확히 일치한다. SVG를 정규화하거나 좌표/쪽 크기를 제외하지 않았다. 기존 실패 증거를 보존하고 실행 설정 차이의 추가 증거를 남겼다. 모델/저장물의 쪽 여백 손실로 분류하지 않는다.

선택은 DEV Cursor 도우미, 클릭/키는 CDP, 숫자 입력은 DOM 이벤트를 썼다. 물리 입력·OS 클립보드/대화상자·설치 앱의 최신 소스 실행·Linux 실행을 검증하지 않았다. dev12 앱은 기존 소스 30601b1 후보이며 최신 수정의 앱 검증으로 주장하지 않는다. 그 앱의 strict ad-hoc 서명은 그대로 유효하다. 전체 Rust lib 단위 검사는 기존 누락 샘플 3개 때문에 실행하지 않았다.

QA는 ../table-size-qa에 있다. 중단 복구 때 백업 579개를 대조하고 변경된 캐시 15개를 먼저 복원했다. 최종 빌드 뒤 변경된 기존 캐시 6개를 다시 복원해 보호 파일 44,512개의 변경/누락 0을 확인했다. 모든 브라우저/서버는 정상 종료됐고 포트 32168/32169는 닫혔다. target 4.5GiB 이하·실제 여유 15GiB 이상을 지켰으며 원본·기존 앱/QA·권한은 보존했다. 새 target·앱/ZIP·삭제 정리·푸시·병합·릴리스는 없다. 원시 실패/성공 로그, 모델, 저장 파일, runtime/source hash, 보호/예산 기록과 Native 바이너리는 별도 QA에 보관했다.
