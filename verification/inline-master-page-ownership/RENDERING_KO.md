# 논리 구역의 쪽별 표시 수정

기존 `570a374` 앱 QA의 31회 관찰 중 23회 불일치는 보존했다. 저장 소유권이
맞아도 렌더러가 물리 루트만 읽어 후속 페이지의 폭과 바탕쪽을 잘못 표시했다.
최신 UI main `bbc2c4d25b015b571068e4e9f38a5d1689021e6f`를 결합했고, 엔진의
쪽별 SVG·렌더 트리·페이지 정보·커서/히트테스트 회귀를 Native/WASM에서 확인했다.
**최종 앱 재검증과 독립 검토는 대기이며 병합 보류다.**

## 이전 비교와 수정 후 결과

| 입력 | 기준 main의 BODY_1 | 기존 PR81의 BODY_1 | 수정 후 Native/WASM |
|---|---|---|---|
| explicit-distinct | 폭 560, MASTER_0 | 폭 793.7, MASTER_0 | 폭 560, MASTER_1 |
| same-geometry | 폭 793.7, MASTER_0 | 동일 | 폭 793.7, MASTER_1 |
| empty-first | 폭 560, MASTER_1 | 폭 793.7, 바탕쪽 없음 | 폭 560, MASTER_1 |
| shared-part | 폭 560, MASTER_0 | 폭 793.7, MASTER_0 | 폭 560, MASTER_0 |
| 물리 구역 HWP 대조군 | 폭 560, MASTER_1 | 동일 | 동일 |

첫 페이지는 원래 정의의 793.7px를 유지하고 empty-first의 첫 바탕쪽은 없다.
기준 main도 첫 페이지에 마지막 구역 폭·바탕쪽을 적용했다. PR81이 루트를 첫
소유자로 바로잡으면서 후속 폭과 빈 바탕쪽 표시 회귀가 드러났으므로, 이를 모두
기존 결함으로 분류하지 않았다. 원본 앱 비교·실패 로그는 별도 QA 증거에 남겼다.

## 구현 계약

- `PageContent.logical_section_para`에 논리 구역을 연 실제 본문 문단 위치를
  보존한다. `None`은 물리 루트다. `MasterPageRef.owner_para_index`도 같은
  주소로 실제 바탕쪽 배열을 조회한다. 문서의 물리 section/paragraph 인덱스는 바꾸지 않는다.
- 직접 본문 secPr 경계에서 이전 페이지를 닫고 새 페이지 정의·단 프레임을 적용한다.
  그 프레임은 연속 페이지에도 유지된다. 문단 구성과 폭 의존 측정도 논리 범위별로
  수행하고 표·문단의 측정 결과 인덱스는 원래 물리 주소로 합친다.
- 페이지 여백·페이지 정보·테두리/배경·활성 바탕쪽 조회가 해당 페이지의 소유자를
  읽는다. 바탕쪽 선택·마지막 쪽 확장 선택은 논리 범위별로 수행하며 기존 홀짝
  선택 정책을 유지한다. 뒤 구역의 단 설정을 앞 구역의 기본값으로 가져오지 않는다.
- 본문 편집·서식·로드 시 필요한 재조판은 문단 소유자의 폭을 사용한다.
  문단 이동 후 과거 논리 소유자 페이지를 수렴 캐시에서 재사용하지 않는다.
  단일 PageDef만 받는 기존 Paginator와 지연 조판은 인라인 구역 문서에서
  동기 Typeset 경로로 대체한다.
- HWPX 저장의 앞머리 `secPr + colPr`는 파서에서 두 비점유 정의 슬롯이다.
  후속 구역의 colPr XML이 실제 방출돼도 그 8유닛은 textpos에 포함되지 않는다.
  정확한 제어 순서·스트림 위치가 0/8인 경우만 보정한다. 편집 전 원본 HWPX 축은
  그대로 보존하고 일반 인라인 colPr는 기존 점유를 유지한다.

## 검증과 한계

저장 행렬은 정상 23종·거절 10종이며 단일 소유자 P2 두 입력의 거절을 유지한다.
쪽별 검사는 12종의 입력·편집·양형식 저장/재열기와 긴 본문의 연속 페이지,
앞 문단 분할 후 소유자 주소 이동, 스냅샷 복원, 커서·히트테스트를 포함한다.
별도 2단 후속 구역 입력으로 첫 구역의 기본 단 설정이 오염되지 않는지도 확인한다.
정확한 실행 수와 해시는 `proof.json`에 기록한다.

긴 한글/영문 본문에서 관찰된 글꼴 폭 오차는 같은 폭의 물리 구역에서도 같다.
이 오차를 고치거나 임의 허용 오차를 넓힌 것으로 보고하지 않는다. 짧은 기본
행렬은 본문 경계도 검사하며, 긴 본문은 물리 대조군과 줄·글자 위치가 동일한지
비교한다. 별도로 발견한 인라인 HWPX 줄 시작 8유닛 오차는 수정 후 그 대조군과
일치했다. 초기 실패 로그는 보존했다.

UI scroll RAF 경합은 main의 독립 PR82 수정이다. 결합된 UI 테스트 78개와 Studio
타입 검사는 통과했지만 이것이 실제 앱 검증은 아니다. 최종 앱 QA는 해당 UI main과
최종 WASM 해시를 함께 고정해야 한다. 정품 한글·물리 입력·서명 패키지·복잡한
인라인 다단/표/각주/부동 개체 조합의 시각 동등성은 이 합성 행렬로 인증하지 않는다.
병합·배포하지 않았다.
