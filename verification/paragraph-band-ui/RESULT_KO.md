# 일반 본문 문단 띠 메뉴 연결

일반 본문의 한 문단에서 **문단 너비100%·두께1mm·검정 채우기·선 없음·문단 기준 사각형**을 넣는 `insert:para-band` 메뉴를 연결했다. 같은 문단에서 다시 실행하면 기존 띠의 두께/면 색을 편집하며 중복 삽입하지 않는다. 띠 선택 후 기존 개체 속성 메뉴도 같은 편집 대화상자를 연다. 대화상자의 지우기와 기존 개체 지우기 메뉴는 같은 삭제 API/기존 InputHandler snapshot·undo 경로를 사용한다.

기본값/확인과 취소를 대화상자로 제공한다. 지원 기본 속성은 두께1~20mm와 단색 면 색이다. 폭100%·문단 위치·선 없음은 유지한다. 본문 텍스트 선택을 교체하지 않으며 해당 문단에 독립 사각형을 추가한다. 기존 절대폭 개체의 일반 속성 대화상자는 유지했다. 실제 한컴 원본 띠 파일의 모든 기본 byte/앵커 속성을 인증한 결과는 아니다. [공식 의미·이전 조사](../paragraph-band-scope/DESIGN_KO.md), [너비 API 기초](../body-rectangle-width/RESULT_KO.md).

## 안전 범위와 필요한 엔진 보완

가로 일반 본문 루트의 한 문단 또는 지원 단순 띠 개체 하나만 처리한다. 다문단/다중 개체·셀/셀 블록·표 선택·각주/머리말·양식/읽기 전용·회전/그룹/다른 개체 선택은 띠 명령에서 무변경 거절한다. 잘못된 두께/색, 적용/종료한 대화상자 재사용과 문서/선택 변경도 거절한다. 같은 문단에 띠가 여러 개이면 대상을 추정하지 않는다.

저장 앵커는 문단 끝의 마지막 제어로 추가하고 화면 위치는 문단 기준으로 지정한다. 이는 앞의 본문 주석/필드/각주와 기존 개체의 제어 번호·직접 서식을 유지하기 위한 범위다. 중간 앵커로 저장된 기존 띠 또는 띠 뒤에 다른 개체가 추가된 경우에는 이 편집·제거를 거절한다. 별도 띠 ID/불명 marker를 새로 넣지 않고 지원되는 Para100%·위치·단색/선 속성으로 식별한다.

처음에는 기존 검증 WASM만으로 연결을 시도했으나, **같은 문단의 주석 FIELD_END를 기존 도형 삭제가 제어 슬롯으로 세어 뒤 글자 서식 참조를 바꾸는 결함**을 재현했다(`probe.log`). UI 우회로 제거를 구현하지 않았다. 기존 `deleteShapeControl`에 문단 끝/마지막 단순 Para100% 사각형의 뒤 텍스트 shift를 생략하는 좁은 보완과 지원 밖 중간 Para100% 삭제의 무변경 거절을 추가했다. Absolute 및 다른 도형의 기존 삭제/크기 경로는 변경하지 않았다. 기존 공유 size resolver·너비 API 계약도 그대로다.

엔진 추가 빌드 전에 target3.75GiB·예상 일시 증가110MiB/최고3.86GiB를 보고했고 target4GiB·QA1GiB·free10GiB 상한을 감시했다. 새 Native 예제를 별도로 쌓지 않고 기존 너비 검증 예제에 독립 UI 저장 대조 모드를 추가했다.

## 보존과 남은 확인

기존 기본 앱/공개 beta.2/dev10·이전 후보와 직전 너비 기초 pkg/QA를 보존했다. 새 WASM은 별도 `paragraph-band-ui-qa/pkg`에만 두었다. 새 앱/배포 패키징·공개 푸시/릴리스·계정/서명/권한 변경은 없었다. 테스트 Node 프로세스는 종료했고 실제 GUI 검증 창은 열지 않았다.

실제 Mac 메뉴 클릭·선택/끌기·물리 IME·한컴 생성 문서/한컴 앱 저장 열기·Linux는 검증하지 않았다. 전체 lib 단위 테스트는 기존 missing include_bytes fixture3개 제한 때문에 재실행하지 않았고 대체/제외를 추가하지 않았다. 중간/복잡 띠의 기본 속성 편집·제거, 임의 offset/회전·그룹·셀/머리말/각주 저작은 다음 지원 범위이며 이번 성공으로 주장하지 않는다.

초기 UI 검사 어댑터의 개체 선택 해제 메서드와 메뉴 selector 반환을 보완한 실패 로그를 최종 통과와 구분해 보존했다. 새로운 엔진 해시·정확한 자원/검증 숫자·보존 해시는 [proof](proof.json), 별도 `../paragraph-band-ui-qa`의 로그/파일/체크포인트에 있다.

이번 자원 최고 target 3.846GiB / 최종 3.749GiB, QA 27.90MiB, disk free 최저 21.51GiB. 보호 대상18개·dev10 QA314개·직전 너비 QA771개 해시가 일치했다. 상한 초과/감시 중단은 없었다.
