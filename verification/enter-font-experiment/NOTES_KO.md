# Enter 글꼴 분류 실험 — 후보 미채택

전체 section 조판이 native Enter pagination의 99% 이상을 차지한다. 8192문단 본문 Enter는 일반문단8193개, 셀 Enter는 일반문단8191개와 표1개를 다시 조판한다. 높이 측정 캐시는 사용되지만 전체 조판은 남는다. 진단과 무효화 범위는 ../enter-pagination-profile에 기록했다. 그 진단의 native debug 절대 시간은 실제 앱 지연과 비교하지 않는다.

같은 font name의 KoPub 분류를 매 문자마다 반복하는 좁은 중복을 실험했다. Unicode 소문자 변환과 기존4개 substring 규칙/Dotum 우선 순위를 그대로 유지하고, 이름8개×256UTF8bytes 이하를 thread-local FIFO에 저장했다. 긴 이름은 기존 계산으로 처리했다. 폭, 굵기/기울임/크기/자간, 메트릭/별칭, 문단/페이지/Document를 캐시하지 않았다. 최대2KiB는 보존 이름 bytes만 의미하며 metadata나 전체 앱 메모리 한도가 아니다.

실제 새 WASM c258e847…에서 문자열 검색·소문자 변환의 CPU 샘플이 거의 사라졌고 문자 폭 결정의 inclusive 비중은 기존43.7~50.6%에서16.4~20.6%로 줄었다. 전체 조판과 할당에서 관측되는 비용은 커졌다. 샘플링으로 전체 지연의 개선을 보장하거나 변화 원인을 확정할 수 없다.

Enter 중앙값(ms), 각 입력 예열3/측정12. 기본 네 모드 자료의 기준은 같은 프로토콜의 이전 b8e14bf 실행이다. 현재 후보 실행은 다른 빌드/검사와 겹치지 않았다. 후속 현재 환경 비교는 실제 UI next-command 한 모드만 실행하며 기준/후보를 연속된 별도 프로세스에서 측정했다.

기본 프로토콜에서 큰 문서 후보는 이전 기준보다 Enter약10.7~10.9%, undo약11.4~11.5% 느렸다. 한 모드의 현재 비교에서는 Enter약34.1~34.2% 빨랐다. 작은 문서도 프로토콜에 따라 기준 시간이 크게 달랐다. WASM 예열/최적화 tier 차이는 가능한 설명일 뿐 아직 확인하지 않았다. **안정적인 전체 지연 개선이 확인되지 않아 후보를 채택하지 않고 프로덕션 engine/src를 b8e14bf와 정확히 같은 상태로 복원했다.** 최종 로컬 WASM도 검증한4ff4199b…으로 복원했다. 후보 패치/엔진/로그/원시값은 별도 QA에 보존했고 패치와 원시 측정 일부는 이 폴더에 있다. 이번 커밋은 진단·검증 도구와 결과만 추가한다.

후보의 정확성 검사는 통과했다. 14글꼴×4서식의 SVG와 모든 글자 판단 trace56개 조합이 기준과 완전히 일치했다. Unicode Kelvin 대소문자·모호한 KoPub 이름·긴 ASCII/한글 이름·미등록/메트릭 글꼴·굵기/기울임/크기/자간/위첨자 및 한글/Latin/공백/탭/구두점/PUA/emoji/조합문자를 포함한다. 56스냅샷 복원과112재열기도 통과했다. 본문/고정1×1셀 각각400페이지의 전후1600개 페이지 SHA256 및 전체 텍스트·스타일 digest가 기준과 일치했고, 각 후보의 undo/redo와 HWP/HWPX재열기12회가 통과했다.

native next-style162/undo-redo288/두형식324/merge36/무변경거절126, 실제 WASM288/UI72/undo-redo576/merge72/거절21 및1224출력의 전체문단·모양run·스타일참조 native 재열기 비교가 통과했다. 스타일전파48/삭제16/셀수식72/회전그룹108/메타데이터8/이벤트8·타원5 회귀도 통과했다. native/WASM strictClippy, 전체 tsc/Vite, UI mock11, 관련 desktop30pass/0fail/1skip/1TODO가 완료됐다. unchanged server socket 테스트는 제외했고 빈 엔진 createEmpty의 기존 TODO는 해결했다고 주장하지 않는다. 후보 웹 asset의 WASM hash도 fresh bindings와 일치했다.

관측 RSS/WASM 한도, target3GiB 감시는 proof.json에 있다. Cargo 임시파일이 삭제되는 순간 du 감시기가1회 실패했지만 해당 테스트 로그는 완료됐고, 감시기를 보완해 재실행/exit0 증거를 확보했다. 네이티브와 WASM GUI/물리 IME, 한컴 재열기, Linux 실기는 미검증이다. 최종 소스의 새 Mac 앱/ZIP은 만들지 않았다. 원본/기본앱/dev3/dev5/공개beta2와 이전 개선은 보존한다. 최신 사용자 지시에 따라 공개 push/release는 보류한다.

다음 확인은 동일한 실행 패턴과 충분히 통제한 WASM 예열/tiering 비교다. 안정적인 비용이 확인된 뒤에도 전체 조판 증분화는 width/wrap band/column/footnote/그림 문맥의 무효화 규칙을 별도로 검토해야 한다. 이번 작업에서 넓은 페이지네이션 의미 변경은 하지 않았다.
