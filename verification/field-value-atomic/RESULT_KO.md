# 필드 값 교체의 변경 전 거절

`d1bf531` 이후 짝이 있는 필드의 `set_field_text_at` 값 교체 경로만 수정했다. production 변경은 `field_query.rs` 한 파일이다. 지원 범위 밖 소유권을 가진 값을 교체하기 전에 검증하며, 정상 값 교체의 이웃 필드 범위를 보존한다.

## 실제 재현

기준 Native 합성자료6개 중 내부 각주/불명 제어/끝 범위 초과/좌표 손상/중첩 필드5개가 교체를 받아들이고 전체 문서와 raw_stream을 변경했다. 끝 범위 초과에서는 `앞🙂옛𐐀값뒤가나끝`이 `앞🙂새🙂`로 바뀌어 원래 뒤 본문4글자가 삭제됐다. 내부 각주 앵커도3에서4로 이동했다. 역전 범위1개는 조회 단계의 unsigned subtraction에서 panic이 났고 이 경우 문서 변경은 없었다. 소스의 검증 누락만으로 손실을 단정한 결과가 아니다.

기준 WASM에서도 저장 가능한 비지원 사례18회(ID/이름, HWP/HWPX 입력)를 모두 받아들였다. 인접한 빈 필드가 있는 정상 값 교체에서 이웃 필드 값이 `새🙂`/`𐐀값`으로 함께 바뀌는 문제도 재현했다. 두 필드가 같은 빈 위치로 합쳐지는 값 비우기는 HWP 재열기에서 필드 순서/내부 슬롯 소유권이 바뀌었다. 전후 전체 Native Debug 문서와 WASM 모델·저장 바이트·재열기 증거를 별도 QA 폴더에 보존했다.

## 수정과 지원 경계

- 문단 위치·짝/제어 축·범위·내부 슬롯·불명 제어·다른 필드와의 겹침을 raw_stream 무효화보다 먼저 검증한다. ID/이름 API가 같은 검증 경로를 사용한다.
- 역전된 범위의 조회 길이는 포화 뺄셈으로 처리해 조회에서 panic 없이 교체 검증까지 도달하도록 한다. 잘못된 범위를 정상 범위로 승인하지 않는다.
- 일반 텍스트 삽입의 같은 경계 포함 규칙이 이웃 필드의 값까지 확장하지 않도록, 편집 전 이웃 범위의 소유권을 복원하고 교체 길이에 맞춰 이동한다.
- 같은 시작점의 빈 필드 소유권이 겹치거나, 값을 비워 인접 필드 시작에 겹치게 되는 경우에는 변경 전에 거절한다. 독립 필드의 일반 값 비우기는 지원한다. 인접 빈 필드들의 저장 순서를 고치는 serializer 작업은 이번 범위에 포함하지 않았다.
- 가상 셀 이름 필드의 `set_cell_field_text` 및 일반 타이핑/삭제 경로는 이번에 수정하지 않았다.

## 최종 자동 검증

| 검사 | 결과 |
|---|---|
| Native 비지원8종 | ID·이름16회 모두 오류 반환; 전체 Document Debug(모든 서식/참조/raw_stream/부가 데이터)와 event log 무변경 |
| Native 정상5개 | emoji/astral 값·독립 값 비우기·인접 필드 분리 보존; snapshot undo/redo10회, HWP/HWPX 재열기10회 |
| WASM 비지원 | 저장 가능한9개 입력 × ID/이름 =18회 거절; 전후 공개 모델·문서 정보·event log와 두 저장 형식의 바이트/손실보고 동일 |
| WASM 정상10개 | 실제 현재 SnapshotCommand undo/redo 각10회, 두 형식 재열기20회; 이웃 필드 값은 빈 값 유지 |
| 이전 누름틀 보존 회귀 | Native 재열기66회; WASM 재열기54회＋기존 실패 사례 별도4회, undo/redo 각24회, 거절14회, 공유 셀 명령6개 |

Native 거절 비교에는 캐시를 제외하지 않았다. 정상 snapshot 복원 비교에서는 기존 renderer의 단일 줄 overflow memo만 제외하고 전체 문서를 비교했다. 저장 재열기는 텍스트·스타일/직접 서식·필드 범위/ID·각주 번호/본문/앵커를 비교했다. WASM 정상 입력은 교체 전에 알려진 기본 BorderFill 차이만 HWPX로 한 번 정규화했다(HWP 입력별78개 `fillType/patternColor/patternType` 차이 기록). 실제 변경/거절 비교에서는 서식이나 참조를 필터링하지 않았다.

잘못된 IR 경계처럼 파일 파서가 정규화하는 자료는 Native에서 검증했다. 불명 제어의 HWPX 형식 변환 전체 보존을 인증하지 않는다. 거절 전후 출력 동일성은 값 교체의 무변경 검증이다. 기존 library unit test 원본3개 누락은 그대로이며 이번에 재실행·대체·우회하지 않았다. 실제 Mac GUI·물리 IME·Linux·앱 통합/패키징은 미검증이다.
