# 다음 작성 기능 선정 및 실제 누락 확인

2026-10-06, `1ec876334` 이후 checkout의 UI/API를 다시 대조했다. 기존 dev.6 기능 대조표는 당시 기록으로 유지한다. 다음 기능 한 가지는 **각주·미주의 선택된 일반 텍스트 직접 글자 서식**이다.

| 검토 기능 | 구현 확인과 선택 판단 |
|---|---|
| 표 글자 서식 | `applyCharFormat`과 기존 셀 경로/F5 처리가 이미 있다. 새 누락으로 취급하지 않았다. |
| 번호·글머리표 | 기존 문단 모양/API 경로가 있다. 이번에 새 기능으로 주장하지 않았다. |
| 중첩 셀 문단 직접 서식 | 직전 커밋 `1ec876334`에서 완료. 이번 최종 WASM으로 108사례와 History 예산 검사를 다시 통과했다. |
| 각주·미주 선택 글자 서식 | 기존 `InputHandler.applyCharFormat`은 각주 모드에서 즉시 반환한다. note 글자 getter/선택 범위 setter도 없었다. 실제 기존 엔진·메서드에서 굵게/기울임 2요청의 dispatch=0, HWPX 바이트·전체 SVG 무변경을 재현했다. |

기준 재현은 `scripts/check-footnote-char-gap.mjs`와 QA 폴더 `baseline/repro/proof.json`에 남겼다. 이 스크립트는 고정한 수정 전 InputHandler와 수정 전 WASM용이다. 최신 엔진으로 실행하는 회귀 스크립트는 `check-footnote-char-wasm.mjs`다.

완료한 범위는 동일 각주/미주의 비어 있지 않은 텍스트 선택에 굵게·기울임·크기·장평·자간과 글자 모양 대화상자의 지원 속성/글꼴을 적용하는 것이다. 기존 혼합 run의 생략 속성, 문단·스타일, 본문·이웃 노트, 번호와 문서 참조를 보존한다. 다중 문단·빈 중간 문단·역방향·Unicode 선택 및 undo/redo 선택 복원을 포함한다.

이 문서는 한컴 전체 기능 완료나 GUI 인증을 뜻하지 않는다. 선택 없는 다음 입력 글자 서식, 개체/필드가 있는 노트 문단, 글자 테두리·배경 확장, 각주 문단 직접 서식은 후속 범위다. 실제 Mac GUI·물리 IME·Linux는 이번에 검사하지 않았다.
